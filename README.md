# Ecommerce-Sales-Analysis

## Overview

This project focuses on analyzing e-commerce sales data and presenting business insights through an interactive Power BI dashboard. The dashboard helps understand sales performance, profitability, customer purchasing behavior, product categories, and payment preferences.

The project uses two CSV datasets, Orders and Order Details, to explore key business metrics and identify trends that can support data-driven decision-making.

## Project Objectives

- Analyze overall e-commerce sales performance.
- Track total sales, profit, quantity, and average order value.
- Identify top-performing states and customers.
- Understand product category and sub-category performance.
- Analyze customer payment preferences.
- Track monthly profit trends.
- Build an interactive dashboard with filters for better data exploration.

## Dataset

The project uses two CSV files:

### 1. Orders.csv

Contains order-level information:

- Order ID
- Order Date
- Customer Name
- State

### 2. Order Details.csv

Contains product and transaction information:

- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- Payment Mode

The two datasets are connected using the Order ID field.

## Dashboard Features

The Power BI dashboard includes:

- **KPI Cards:** Display total sales amount, total profit, quantity sold, and average order value.
- **Sales by State:** Visualizes sales distribution across different states.
- **Quantity by Category:** Shows the contribution of different product categories.
- **Payment Mode Analysis:** Displays customer preferences across different payment methods.
- **Top Customers:** Identifies customers contributing the highest sales amount.
- **Monthly Profit Analysis:** Tracks profit and loss across different months.
- **Profit by Sub-Category:** Compares profitability across product sub-categories.
- **Interactive Filters:** Allows users to explore data using quarterly buttons and a state dropdown.

## Key Business Insights

Based on the dashboard analysis:

1. **Regional Performance:** Maharashtra recorded the highest sales, followed by Madhya Pradesh.
2. **Category Performance:** Clothing contributed 63% of the total quantity sold, followed by Electronics (21%) and Furniture (17%).
3. **Payment Preferences:** Cash on Delivery (COD) was the most frequently used payment mode, accounting for 44%, followed by UPI at 21%.
4. **Monthly Profit Trends:** January and November recorded the highest profits, while May, July, September, and December showed negative profits.
5. **Sub-Category Performance:** Printers and Bookcases were among the most profitable sub-categories.
